# Sales Performance and Revenue Leakage Analysis Using SQL

## Project Overview
This project analyzes sales performance, customer purchasing behavior, and revenue leakage using SQL. The dataset was imported into Microsoft SQL Server and analyzed using SQL queries to generate meaningful business insights.

The project focuses on:
- Gross sales performance
- Completed vs unrealized revenue
- Product performance
- Referral channel effectiveness
- High-value customers and orders
- Revenue leakage from cancelled, returned, and pending orders

---

## Objectives
The main objectives of this project were to:

- Build and manage a SQL database
- Import CSV sales data into SQL Server
- Perform business analysis using SQL queries
- Identify top-performing products and channels
- Analyze unrealized revenue and sales leakage
- Generate actionable business insights

## Key Analysis Performed
The following analyses were carried out:

- Product revenue analysis
- Referral source analysis
- Payment method analysis
- Order status analysis

- Highest-value orders analysis

- Revenue contribution analysis

- Cancelled, returned, and pending sales analysis

---

## Key Findings
- Unrealized revenue exceeded completed revenue, indicating major revenue leakage.
- Chair and Printer products generated the highest revenue.
- Phone products recorded the lowest revenue contribution.
- Instagram and Email were the strongest-performing referral channels.
- Sales revenue declined from 2023 to 2025.
- Cancelled orders contributed the highest unrealized revenue loss.
- Several high-value transactions significantly influenced total revenue.

---

## Business Recommendations
- Improve order fulfillment and payment confirmation processes.
- Reduce cancelled and returned orders.
- Follow up on pending orders more efficiently.
- Increase marketing efforts on high-performing referral channels.
- Monitor high-value transactions for business opportunities.

---

## Conclusion
This project demonstrates how SQL can be used to transform raw sales data into valuable business insights. The analysis helped identify revenue trends, customer behavior patterns, and operational weaknesses affecting business performance.

The findings from this project can support better decision-making, improve operational efficiency, and help reduce revenue leakage within the business.
