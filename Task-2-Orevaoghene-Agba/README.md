# Exploratory Data Analysis (EDA) – Sales Performance Analysis

## Project Overview
This project focuses on exploratory data analysis (EDA) using Excel to identify sales trends, customer behaviour patterns, revenue leakage, and operational insights from the sales dataset.

The analysis was performed using PivotTables, descriptive statistics, and business analysis techniques to transform raw sales data into meaningful insights.

---

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Descriptive Statistics

---

## Analysis Performed
- Gross sales analysis
- Completed sales analysis
- Unrealized sales analysis
- Correlation analysis
- Outlier and distribution analysis

---

## Key Insights
- Unrealized revenue exceeded completed sales revenue.
- Chair and Printer products generated the highest sales revenue.
- Instagram and Email were the strongest referral channels.
- Larger cart sizes were more likely to become pending or cancelled orders.
